# 이상탐지 이전의 데이터 감사

## 산업 검사 데이터의 라벨 출처와 판정 렌더링 누수를 모델 학습 전에 진단하는 연구

작성일: 2026-08-15
현재 단계: 6단계 완료 — Siemens 논문 프로토콜 부분 재현

---

## 1. 연구 배경

산업 검사 자동화 연구는 일반적으로 데이터를 받은 뒤 이상탐지 또는 분류 모델을 적용하고, AUROC와 같은 성능을 비교하는 순서로 진행된다. 이 순서는 데이터의 라벨과 이미지가 실제로 무엇을 나타내는지가 명확하다는 전제를 둔다.

그러나 현장 데이터에서는 이 전제가 자주 성립하지 않는다.

- 불합격 라벨이 사람의 독립 판정이 아니라 기존 검사 설비가 계산한 출력일 수 있다.
- 저장된 이미지가 원본 영상이 아니라 판정 결과와 ROI 테두리가 그려진 결과 화면일 수 있다.
- 수천 개의 검사 행이 실제로는 몇 개의 제품 또는 몇 건의 결함 사건에서 반복 생성된 것일 수 있다.
- 무작위 분할에서는 높게 나온 성능이 새로운 날짜·제품·라인에서는 사라질 수 있다.

이 경우 모델은 실제 결함보다 기존 검사기의 판정 규칙, 테두리색, 촬영 날짜 또는 반복 개체를 학습할 수 있다. 높은 성능은 얻을 수 있지만, 그것이 기존 설비보다 실제 결함을 더 잘 찾는다는 의미는 아니다.

Shortcut learning 연구는 IID 평가만으로는 모델이 의도한 해결법을 학습했는지 지름길을 학습했는지 구분하기 어렵다고 설명한다. 최근 산업 이상탐지 연구도 기존 벤치마크의 포화, 시간 분포 변화, 실제 요구사항과 표준 성능지표의 불일치를 지적한다.

본 연구는 모델 구조보다 앞단에 있는 질문을 다룬다.

> 이 데이터로 모델을 학습하고 평가했을 때, 그 성능을 실제 결함 검출 성능으로 해석할 수 있는가?

## 2. 현재 사례에서 확인된 문제

자동차 퓨즈박스 비전검사 데이터는 SQLite 로그 100개, ROI 판정 7,800행, 결과 이미지 364장으로 구성되어 있다.

현재까지 확인한 주요 관측은 다음과 같다.

| 관측 | 현재 결과 | 의미 |
|---|---:|---|
| 기존 설비 판정 규칙 재현 | 7,800/7,800 | 저장 라벨은 독립 정답이 아니라 설비 출력과 결정적으로 연결됨 |
| 이미지 테두리색의 판정 예측 | 정직 프로토콜 AUROC 1.000 | 모델이 결함 대신 렌더링된 판정을 읽을 수 있음 |
| 날짜별 최빈 라벨 재대입 | 정확도 96.2% | 정상과 불합격 이미지의 수집 시점이 분리되어 있음 |
| 날짜 단위 외삽 | date-only AUROC 0.526 | 96.2%는 새로운 날짜에 대한 예측력이 아니라 수집 지원 편향임 |
| 독립 불합격 사건 | 3건 | 20개 불합격 ROI 행을 독립 표본으로 취급할 수 없음 |
| 오버레이 제거 후 모델 | PatchCore 0.558, CLIP 0.506 | 렌더링 단서를 제거하면 현재 표본으로 성능을 판단하기 어려움 |

여기서 판정 규칙이 100% 복원된다는 사실이 설비 판정이 반드시 틀렸다는 뜻은 아니다. 실제 부품 누락을 설비가 올바르게 검출한 사례도 있다.

정확한 문제는 다음과 같다.

> 설비 출력으로 모델을 학습할 수는 있지만, 독립된 정답이 없으므로 기존 설비보다 실제 결함 검출이 개선되었는지는 평가할 수 없다.

## 3. 문제정의

### 3.1 연구 문제

현재의 산업 데이터 준비도 도구는 결측, 중복, 클래스 불균형, 라벨 오류, 공정성, FAIR 원칙 등을 폭넓게 다룬다. 하지만 산업 검사에서는 다음과 같은 **과업 특화 데이터 생성 병리**가 추가로 중요하다.

1. **라벨 종속성**: 평가 라벨이 평가 대상인 기존 설비의 출력인가.
2. **판정 렌더링 누수**: 이미지에 정답을 나타내는 색·테두리·텍스트가 포함되었는가.
3. **독립 단위 붕괴**: 행 수가 제품·바코드·사건 수를 과장하는가.
4. **배치 조건 불일치**: 무작위 분할과 시간·제품·라인 분할의 성능이 다른가.
5. **사양 부재**: 무엇이 보이는지와 무엇이 정상이어야 하는지를 구분할 정보가 존재하는가.

본 연구는 이 병리들을 모델 학습 전에 측정하고, 측정값이 이후의 성능 붕괴를 예측하는지 검증한다.

### 3.2 연구 질문

**RQ1.** 라벨 종속성, 판정 렌더링 누수, 시간 교락, 독립 단위 붕괴를 모델 학습 전에 자동으로 검출할 수 있는가?

**RQ2.** 사전 감사 지표가 무작위 평가와 실제 배치 조건 평가 사이의 성능 차이를 예측하는가?

**RQ3.** 동일한 감사 절차가 다른 산업 데이터의 알려진 병리를 검출하면서 깨끗한 데이터에서는 낮은 오탐률을 유지하는가?

### 3.3 연구 가설

- **H1:** 병리의 주입 강도가 증가하면 대응 감사 지표가 단조롭게 증가한다.
- **H2:** 감사 위험도가 높을수록 무작위 분할과 시간·개체 분할 사이의 성능 격차가 커진다.
- **H3:** 라벨 출처가 독립적이고 원본 이미지가 제공되는 데이터에서는 라벨 종속성과 렌더링 누수 진단이 발동하지 않는다.

연구가 다시 확장되는 것을 막기 위해 이번 단계의 제외 범위를 먼저 정한다.

- 새로운 SOTA 이상탐지 모델 비교
- LLM 기반 질문 생성 성능 비교
- 온톨로지 또는 지식그래프 구축
- 조달 비용 등급의 효과 주장

- 데이터 표준 제정 주장

암묵지와 사양 질의는 폐기하는 것이 아니라 후속 연구로 분리한다. 현재 단계의 산출물은 검사 데이터의 증거 카드와 감사 프로토콜이다.

## 5. 전체 연구 설계

### 단계 0. 증거 고정과 재현성 점검

목적은 논문에 들어갈 모든 수치를 입력 파일과 계산 정의에 연결하는 것이다.

수행 항목:

- 핵심 수치를 원자료 산출물에서 다시 계산한다.
- `행`, `제품`, `바코드`, `사건`, `날짜` 단위를 구분한다.
- 재대입 정확도와 외삽 성능을 다른 이름으로 기록한다.
- 사람 평가에서 민감도, 특이도, 반복 일치도를 함께 계산한다.
- 오래된 요약 파일과 최신 사례 기록의 불일치를 탐지한다.
- 각 결과에 입력 파일, 정의, 값, 단위, 해석을 기록한다.

산출물:

- `evidence_ledger.csv`
- `current_metrics.json`
- `current_audit_report.md`

완료 조건:

- 같은 입력에서 같은 수치가 재현된다.
- 서로 다른 정의의 값이 하나의 성능값으로 혼용되지 않는다.
- 불일치가 남아 있으면 논문 초록 수치를 고정하지 않는다.

### 단계 1. 합성 병리 주입 벤치마크

깨끗한 합성 데이터에 병리를 하나씩 통제하여 주입한다.

| 병리 | 주입 방법 | 대응 지표 |
|---|---|---|
| 라벨 순환 | 독립 라벨 일부를 기존 설비 출력으로 교체 | 설비 규칙–관측 라벨 일치율 |
| 판정 렌더링 누수 | 판정에 비례하는 가상 색상 특징 추가 | 단일 렌더링 특징 AUROC |
| 날짜 교락 | 양성과 음성이 특정 날짜 집합에 집중되도록 변경 | 날짜 재대입 정확도와 기준선 대비 lift |
| 사건 복제 | 동일 양성 사건을 여러 행으로 반복 | 양성 행/양성 사건 비율 |

기본 실험 설정:

- 병리 강도: 0, 0.25, 0.50, 0.75, 1.00
- 강도별 100개 시드
- 시드별 300개 독립 사건
- 한 번에 병리 하나만 주입

주 결과:

- 강도별 감사 지표 평균과 범위
- 깨끗한 대조군과 최대 병리의 분리 정도
- 지표의 단조성

실패 조건:

- 병리 강도가 커져도 지표가 증가하지 않는다.
- 깨끗한 데이터에서 병리 데이터와 유사한 값이 반복된다.
- 지표가 특정 클래스 비율에서 원리적으로 발동할 수 없다.

### 단계 2. 성능 붕괴 예측 실험

단계 1을 통과한 지표만 사용한다.

각 합성 데이터에서 동일 모델을 두 방식으로 평가한다.

1. 무작위 행 분할
2. 사건·개체·날짜 단위 분할

주 지표:

```text
평가 격차 = 무작위 분할 성능 - 배치 조건 분할 성능
```

분석:

- 감사 지표와 평가 격차의 Spearman 상관
- 병리 종류와 강도를 설명변수로 한 회귀
- 사건 수에 따른 검정력 곡선

이 단계에서 감사 지표가 이후 성능 붕괴를 예측하면, 연구 기여는 체크리스트가 아니라 사전 예측 도구가 된다.

#### 2단계 최소 구현

외부 패키지 없이 재현 가능한 대각선 선형 판별기를 기준 모델로 사용한다. 각 특징의 양성·음성 평균 차이를 학습 데이터의 분산으로 표준화해 가중치로 사용한다. 사건이 행 단위로 복제된 경우에는 고용량 모델의 개체 암기를 모사하기 위해 학습 세트에서 본 사건의 라벨을 우선 반환한다.

세 가지 평가를 동시에 기록한다.

| 평가 | 학습/시험 구성 | 답하는 질문 |
|---|---|---|
| 무작위 행 분할 | 개발 데이터의 행을 무작위 70/30 분할 | 일반적인 평가에서 얼마나 높게 보이는가 |
| 사건 그룹 분할 | 동일 사건의 모든 행을 한쪽에만 배치 | 반복 사건 누수를 제거하면 얼마나 남는가 |
| 배치 평가 | 개발 기간 전체로 학습하고 새 사건·새 시점·원본 특징으로 평가 | 실제 배치 조건에서 얼마나 남는가 |

주 결과는 `무작위 행 분할 AUROC - 배치 AUROC`다. 보조 결과는 `무작위 행 분할 AUROC - 사건 그룹 분할 AUROC`다.

내부 파일럿 판정 기준은 결과 확인 전에 다음과 같이 둔다.

- 병리 전용 감사 지표와 주 성능 격차의 Spearman ρ가 0.50 이상
- 최대 병리 강도의 평균 격차가 강도 0보다 0.05 이상 큼

두 조건 중 하나라도 충족하지 않으면 해당 감사 지표는 성능 붕괴 예측 지표로 채택하지 않는다. 이 기준은 내부 합성 파일럿을 통과하기 위한 기준이며 외부 타당성 기준은 아니다.

#### 2단계 내부 파일럿 결과

100시드, 개발·배치 각 300사건으로 총 2,000회를 실행하였다.

| 병리 | 감사 지표 | ρ(감사, 주 격차) | 강도 0 격차 | 최대 강도 격차 | 증가 | 내부 판정 |
|---|---|---:|---:|---:|---:|---|
| 라벨 순환 | 설비 규칙–라벨 일치율 | 0.874 | 0.004 | 0.295 | 0.290 | 통과 |
| 판정 렌더링 | 렌더링 특징 AUROC | 0.679 | -0.007 | 0.218 | 0.225 | 통과 |
| 날짜 교락 | 날짜 특징 AUROC | 0.731 | -0.007 | 0.222 | 0.229 | 통과 |
| 사건 복제 | 양성 행/양성 사건 비율 | 0.573 | -0.007 | 0.166 | 0.173 | 통과 |

네 병리 모두 사전에 고정한 내부 기준을 통과하였다. 그러나 병리별 해결 방법은 같지 않았다.

- 사건 그룹 분할은 사건 복제에서 무작위 평가의 낙관성을 제거했다.
- 라벨 순환은 사건 그룹 분할 후에도 남았다. 독립 정답이 필요하다.
- 렌더링 누수는 사건 그룹 분할 후에도 남았다. 판정이 그려지지 않은 원본 자산이 필요하다.
- 날짜 교락은 같은 기간 안의 사건 그룹 분할로 해결되지 않았다. 미래 시점 평가가 필요하다.

따라서 “그룹 분할을 사용하라”는 단일 처방으로는 부족하다. 감사 결과가 병리별로 필요한 추가 증거를 결정해야 한다.

이 결과는 합성 생성 과정 안의 내부 구성 타당도이며 외부 검증 결과가 아니다. 네 지표는 다음 단계의 외부 검증 후보로만 채택한다.

### 단계 3. 외부 검증

외부 데이터에는 단계 1과 2에서 고정한 지표와 임계값만 적용한다.

후보 데이터:

- **Siemens SMT AOI:** 작업자 재판정 라벨과 132일 시간축. 시간 변화가 알려진 양성 사례.
- **MVTec AD 2:** 독립 평가 서버와 원본 이미지가 존재하는 음성 대조 사례.
- **슈타겐:** 판정 렌더링과 비독립 라벨이 존재하는 현장 사례.

외부 데이터를 본 뒤 임계값을 수정하면 확인 실험이 아니라 추가 탐색으로 기록한다.

#### 3단계 고정 프로토콜

첫 외부 사례는 [Siemens SMT AOI 공개 데이터](https://data.mendeley.com/datasets/99jzmh9658/1)로 정했다. 이 데이터는 한 생산 라인에서 132일 동안 수집된 AOI 후보를 MIS 작업자가 false call과 true defect로 재판정한 440,274행의 테이블이다. 공식 저장소의 `dataset.csv`와 `mapping.json`을 사용했고, 다운로드 후 파일 크기와 SHA-256을 검증했다. 원자료는 CC BY-NC 3.0 표시와 Siemens Legal Notice에 따라 비상업적 논문 연계 테스트 용도로만 사용한다.

외부 데이터의 결과를 계산하기 전에 다음을 고정했다.

- 모델 입력은 inspection type별 물리 측정값만 사용한다. timestamp와 meta 열은 제외한다.
- 같은 대각선 선형 판별기를 행 무작위, timestamp 그룹, 앞 70%→뒤 30% 미래 시간 분할로 평가한다.
- 무작위 AUROC와 그룹·미래 AUROC의 차이가 0.05 이상이면 평가 취약성 진단을 발동한다.
- 날짜별 최빈 라벨 재대입 정확도의 전체 최빈값 대비 lift가 0.05 이상이면 날짜 신호를 발동한다.
- 외부 결과를 본 뒤 만든 지표와 해석은 사후 탐색으로 분리하며 확증 판정을 바꾸지 않는다.

#### 3단계 결과

| 항목 | 결과 | 사전 판정 |
|---|---:|---|
| 전체 행 / true defect 행 | 440,274 / 4,622(1.050%) | 심한 클래스 불균형 |
| 고유 timestamp / 양성 timestamp | 39,742 / 875 | 행과 PCB 단위 분리 필요 |
| 양성 행 / 양성 timestamp | 5.282 | 비독립 행 경고 발동 |
| 날짜 정확도 lift | 0.000 | 미발동 |
| 행 무작위 AUROC | 0.741 | 비교 기준 |
| timestamp 그룹 AUROC | 0.698 | 격차 0.043, 미발동 |
| 미래 시간 AUROC | 0.727 | 격차 0.014, 미발동 |

확증 결과만 보면 네 진단 중 Siemens에서 직접 적용 가능한 비독립 행 진단만 발동했다. 라벨 순환은 작업자 재판정이라는 출처가 문서화된 음성 대조이지만, 데이터가 AOI defect 후보만 포함하므로 전체 검사기의 민감도와 false negative를 평가할 수 없다. 판정 렌더링 누수는 이미지가 없는 테이블이므로 적용 불가다.

사후 탐색에서는 두 가지가 확인됐다.

- timestamp 자체의 방향무관 AUROC는 0.642였다.
- 미래 5구간 AUROC는 0.545~0.874로 range 0.329였다.

즉, 시간에 따른 불안정성은 존재하지만 날짜 최빈값 정확도와 전체 미래 구간을 합친 AUROC 격차가 이를 놓쳤다. 첫 지표는 1.05% 양성률에서 모든 날짜의 최빈값이 음성이 되어 무력해졌고, 두 번째 지표는 좋은 시기와 나쁜 시기를 하나로 합치면서 국소 붕괴를 평균냈다.

이 결과는 “외부 검증 성공”으로 포장하지 않는다. 현재 증거가 지지하는 결론은 다음과 같다.

> 행 수를 독립 사건 수로 오인하는 문제는 외부 사례에서 재현되었다. 그러나 현재 날짜 정확도 lift와 전체 시간 집계 격차는 희귀 결함과 국소 시간 붕괴에 충분히 민감하지 않다.

#### 다음 확인 실험으로 넘길 수정안

Siemens 결과를 보고 만든 다음 항목은 동일 데이터에서 확증하지 않고 개발안으로만 기록한다.

1. 날짜 정확도 lift를 클래스 불균형에 강한 timestamp-only AUROC 또는 balanced accuracy로 교체한다.
2. 전체 미래 구간 평균뿐 아니라 최소 양성 수를 만족하는 최악 시간 구간의 하락폭을 사전에 등록한다.
3. AUROC와 별도로 현장 목표인 defect slip rate와 manual volume reduction을 고정 임계값에서 평가한다.
4. 수정 지표의 임계값을 고정한 뒤 두 번째 외부 데이터에서 확인한다.

### 단계 4. 시간 강건성과 업무지표 후속 개발

이 단계는 3단계 Siemens 결과를 본 뒤 설계했으므로 외부 확증이 아니라 개발 분석이다. [Pfab & Rothering의 연구 방법론](https://arxiv.org/abs/2506.14521)에서 사용한 업무 관점을 따라 defect slip rate 1% 이하와 false-call volume reduction 40% 이상을 동시에 요구했다.

앞 70% 학습 기간에서 slip rate 1% 이하를 만족하는 가장 높은 점수 임계값을 정하고, 뒤 30%와 미래 5구간에서는 임계값을 바꾸지 않았다.

| 항목 | 결과 | 해석 |
|---|---:|---|
| timestamp-only 방향무관 AUROC | 0.642 | 클래스 불균형에 강한 시간 신호 후보 발동 |
| 행 무작위 AUROC | 0.741 | 일반 평가 기준 |
| 최악 유효 미래 구간 AUROC | 0.545 | true defect 100건 이상 구간 |
| 무작위–최악 미래 구간 격차 | 0.196 | 국소 붕괴 후보 발동 |
| 학습 slip / volume reduction | 0.99% / 2.73% | volume 목표 미달 |
| 미래 전체 slip / volume reduction | 1.60% / 2.66% | 두 목표 동시 미달 |
| 미래 목표 미달 구간 | 5/5 | 단, 학습 feasibility도 미달 |

이 결과는 두 층으로 해석해야 한다.

1. 행 무작위 AUROC 0.741만으로는 운영 불가능성을 알 수 없다. 업무지표를 함께 보고해야 한다.
2. 선형 기준 모델이 학습 기간의 volume reduction 40%부터 달성하지 못했으므로, 미래 실패를 시간 드리프트의 인과적 결과로 돌릴 수 없다.

따라서 다음 비교 모델은 미래 데이터를 보기 전에 고정하되, 먼저 학습 기간에서 slip≤1%와 volume reduction≥40%를 동시에 충족하는지 검사한다. 이 feasibility gate를 통과한 모델만 시간 강건성 평가로 넘긴다. 이 순서를 지키면 “애초에 약한 모델”과 “시간이 지나 무너진 모델”을 구분할 수 있다.

### 단계 5. 고정 비선형 모델 feasibility gate

선형 모델 결과를 본 뒤 단일 비선형 기준 모델을 고정했다. HistGradientBoosting의 설정, 물리 특징 65개와 inspection type, 50/20/30 시간 분할을 실행 전에 Git에 기록했다. 앞 50%로 모델을 학습하고 다음 20% calibration에서 slip rate 1% 이하를 만족하는 임계값을 선택했으며, 마지막 30%에서는 임계값을 변경하지 않았다.

| 구간 | AUROC | slip rate | volume reduction | gate |
|---|---:|---:|---:|---|
| 학습 50% | 0.997 | 0.00% | 7.01% | 참고 |
| calibration 20% | 0.870 | 0.62% | 1.65% | 미달 |
| 미래 30% | 0.878 | 0.85% | 3.16% | 미달 |

미래 구간별 AUROC는 0.799~0.963이었고 slip rate는 네 구간에서 1% 이하였다. 그러나 volume reduction은 1.0~7.5%에 그쳐 모든 구간이 40% 목표에 미달했다.

이 결과가 지지하는 결론은 다음과 같다.

> 좋은 AUROC는 희귀하지만 치명적인 결함을 99% 이상 보존하면서 수작업 물량을 40% 줄일 수 있다는 뜻이 아니다.

Calibration gate가 실패했으므로 미래 결과를 시간 드리프트의 효과로 해석하지 않는다. 또한 같은 Siemens 데이터에서 모델을 임의로 추가하며 gate 통과 모델을 찾으면 사후 선택 편향이 생긴다. 다음 단계는 새로운 모델 탐색이 아니라, 원 논문이 공개한 방법·전처리·평가 정의의 직접 재현으로 둔다. 재현 후에도 차이가 남으면 특징 구성, 임계값 정의, 표본 단위 중 어디서 차이가 발생하는지 감사한다.

### 단계 6. Siemens 논문 프로토콜 부분 재현

원 논문에 공개된 전체 데이터의 40% hyperparameter 학습, 10% 무작위 test, 뒤 50%를 5개 미래 구간으로 나누는 절차와 5-fold 임계값 선택을 재구성했다. 인용된 GitLab 코드는 인증 없이는 접근할 수 없고 Bayesian optimization search space와 최종 hyperparameter도 논문에 없으므로, 고정 Random Forest를 사용한 프로토콜 부분 재현으로 범위를 제한했다.

| 구간 | 재현 slip | 논문 RFC2 slip | 재현 volume | 논문 RFC2 volume |
|---|---:|---:|---:|---:|
| 무작위 test | 1.16% | 1.0% | 71.58% | 89.7% |
| 미래 1 | 3.58% | 10.2% | 38.50% | 66.7% |
| 미래 2 | 1.94% | 14.6% | 38.33% | 52.4% |
| 미래 3 | 2.44% | 15.0% | 50.85% | 65.4% |
| 미래 4 | 7.21% | 10.9% | 54.08% | 76.0% |
| 미래 5 | 7.60% | 11.0% | 33.68% | 39.7% |

10시드 중 무작위 test gate는 4회 통과했고, 미래의 50개 시드-구간은 모두 두 업무목표를 동시에 달성하지 못했다. 따라서 무작위 test에서 미래 평가로 이동할 때 업무 성능이 무너지는 정성적 현상은 재현됐다. 그러나 논문 RFC2와 절대 수치 차이가 크므로 모델 자체의 재현이라고 주장하지 않는다. 이 결과는 ‘좋은 무작위 평가가 미래 운영 성능을 보장하지 않는다’는 연구 문제를 지지하는 재현 증거로 사용한다.

## 6. 데이터 분할과 통계 원칙

- ROI 행을 독립 표본으로 취급하지 않는다.
- 가능한 경우 제품, 바코드, 사건 또는 날짜 단위로 분할하고 부트스트랩한다.
- 무작위 분할은 비교 대상으로만 사용하고 최종 성능으로 사용하지 않는다.
- 임계값은 합성 개발 세트에서 정한 뒤 외부 데이터 적용 전에 고정한다.
- 양성 사건 3건에서 얻은 AUROC는 점추정치보다 신뢰구간과 판정 불가능성을 우선 보고한다.
- 음성 대조 25회에서 오탐 0건은 오탐률 0%로 쓰지 않는다. 95% 상한은 약 11.3%다.
- 오탐률 1% 미만을 0회 관측으로 주장하려면 최소 299개의 독립 음성 대조가 필요하다.

## 8. 암묵지 연구와의 연결

본 연구는 암묵지 연구를 직접 완성하지 않는다. 대신 다음 경계를 만든다.

| 데이터로 계산 가능한 것 | 사람 또는 외부 사양이 필요한 것 |
|---|---|
| 판정 규칙, 누수, 반복, 분포, 시간 교락 | 무엇이 정상이어야 하는지, 예외가 의도된 것인지, 실제 재작업이 있었는지 |

후속 연구에서는 계산으로 해소되지 않는 잔여만 질문 대상으로 삼는다. 다만 이를 암묵지라고 부르기 위해서는 실제 전문가 응답, 응답 비용, 반복 신뢰도와 현장 효과를 측정해야 한다.

후속 논문 후보:

> 신규 품종 사양 구축을 위한 위험 통제형 선택적 질의

필요 조건:

- 여러 라인 또는 충분한 수의 품종 사양표
- 신규 품종의 정답 사양
- 실제 작업자 응답과 소요시간
- 질문 전후의 설정 오류 또는 온보딩 시간 비교

## 11. 현재 단계의 최종 판정

1. 핵심 수치–입력–계산 정의 연결: 충족.
2. 네 합성 병리의 내부 구성 타당도: 충족.
3. Siemens 외부 사례의 비독립 행 진단: 충족.
4. Siemens 외부 사례의 시간 취약성 확증 진단: 미충족.
5. Siemens 논문 프로토콜의 정성적 시간 취약성 재현: 충족. 단, 절대 수치의 완전 재현은 미충족.

따라서 논문 주장을 “네 병리를 자동 검출하는 완성된 도구”로 두면 안 된다. 현재 단계에서 방어 가능한 기여는 문제 형식화, 재현 가능한 감사 프로토콜, 비독립 단위의 외부 재현, 그리고 희귀 결함·국소 드리프트에서 무작위 평가가 낙관적이라는 실증이다. 다음 단계는 Siemens에서 모델을 더 탐색하는 것이 아니라 수정된 시간 진단을 독립적인 두 번째 외부 데이터에서 확인하는 것이다.
