# 산업 검사 데이터 감사 연구 — 현재 진행 현황

> 업데이트: 2026-08-15
> 현재 상태: 0~6단계 완료, 두 번째 외부 데이터 검증 전

---

## 1. 이 연구는 무엇을 하려는가

산업 검사 데이터에 모델을 적용하기 전에, 데이터와 라벨이 실제 결함을 평가하기에 적합한지 먼저 감사하는 연구다.

현장 데이터에서는 높은 AUROC가 나와도 다음 문제가 숨어 있을 수 있다.

- 저장 라벨이 사람의 독립 판정이 아니라 기존 검사 설비의 규칙을 반복할 수 있다.
- 이미지에 판정 테두리나 결과 문자가 포함되어 모델이 실제 결함 대신 판정 흔적을 학습할 수 있다.
- 수천 개의 행이 실제로는 소수 제품이나 결함 사건의 반복일 수 있다.
- 무작위 분할 성능이 높아도 새로운 날짜와 생산 구간에서는 업무목표를 달성하지 못할 수 있다.

따라서 현재의 중심 질문은 다음과 같다.

> 모델 성능을 비교하기 전에 라벨 출처, 판정 렌더링 누수, 비독립 반복, 시간 교락을 측정하면 낙관적인 성능평가 위험을 미리 발견할 수 있는가?

---

## 2. 연구 범위

### 현재 논문에서 다루는 것

1. 라벨 순환성: 저장 라벨이 기존 설비 판정 규칙을 얼마나 재현하는가
2. 판정 렌더링 누수: 테두리·문자·색상만으로 라벨을 예측할 수 있는가
3. 사건 중복: 행 수와 독립 제품·결함 사건 수가 얼마나 다른가
4. 날짜 교락과 시간 취약성: 무작위 평가와 새 날짜·새 구간 평가가 얼마나 다른가
5. AUROC와 실제 업무지표의 차이: defect slip rate와 volume reduction을 동시에 달성하는가

### 현재 논문에서 직접 다루지 않는 것

- 암묵지 자체의 자동 추출
- 현장 전문가 질의의 효과 검증
- 신규 품종 사양 자동 생성
- 특정 AI 모델의 최고 성능 경쟁

암묵지는 폐기한 주제가 아니다. 데이터 감사 후에도 계산으로 결정할 수 없는 정상 기준, 의도된 예외, 실제 재작업 여부를 전문가에게 묻는 후속 연구로 분리한다.

## 3. 지금까지 완료한 단계

### 단계 0. 현장 데이터 감사와 증거 고정 — 완료

로컬 자동차 퓨즈박스 검사 데이터를 다시 계산하고, 서로 다른 수치 정의와 오래된 요약 파일을 분리했다.

- 제품 100개
- ROI 판정 7,800행
- 결과 이미지 364장
- 설비 판정 규칙 재현율 1.0
- 날짜 재대입 정확도 0.962, 날짜 LODO AUROC 0.526
- 테두리 적색 특징 LODO AUROC 1.0
- 오버레이 제거 후 PatchCore LODO AUROC 0.558
- 사람 반복 판정 일치 5/12
- analyst log 실제 17건과 기존 summary 6건의 불일치 발견

현재 데이터는 모델 성능 논문보다 모델링 전 데이터 감사 사례에 더 적합하다고 판단했다.

### 단계 1. 합성 병리 주입 벤치마크 — 완료

4개 병리 × 5개 강도 × 100개 시드로 총 2,000회 합성 실험을 수행했다.

| 병리 | 전용 감사 지표 | 강도 증가에 따른 결과 |
|---|---|---|
| 라벨 순환성 | label rule recovery | 0.771 → 1.000 |
| 판정 오버레이 | overlay AUC | 0.496 → 0.983 |
| 날짜 교락 | date lift | 0.000 → 0.121 |
| 사건 중복 | 양성 행/사건 비율 | 1.000 → 10.000 |

네 지표 모두 병리 강도에 따라 증가해 내부 단조성 기준을 통과했다. 이는 지표가 의도한 합성 병리에 반응한다는 뜻이며, 실제 산업 데이터 일반화가 증명됐다는 뜻은 아니다.

### 단계 2. 감사 지표와 성능 붕괴의 연결 — 완료

감사 지표가 무작위 행 분할과 새 사건·새 시점 평가 사이의 AUROC 격차를 예측하는지 확인했다.

| 병리 | 감사 지표–성능 격차 Spearman ρ | 최대 강도 격차 증가 | 판정 |
|---|---:|---:|---|
| 라벨 순환성 | 0.874 | 0.290 | 통과 |
| 판정 오버레이 | 0.679 | 0.225 | 통과 |
| 날짜 교락 | 0.731 | 0.229 | 통과 |
| 사건 중복 | 0.573 | 0.173 | 통과 |

사전 기준인 ρ≥0.50과 격차 증가≥0.05를 4개 병리 모두 통과했다. 아직 합성 생성 과정 내부의 구성 타당도 결과이며 외부 일반화 결과는 아니다.

### 단계 3. Siemens SMT AOI 외부 검증 — 완료

132일 동안 수집된 Siemens 공개 데이터 440,274행에 고정된 감사 프로토콜을 적용했다.

- true defect 4,622행, 전체의 1.05%
- 고유 PCB timestamp 39,742개
- 양성 행/양성 timestamp 비율 5.282: 비독립 행 경고 발동
- 행 무작위 AUROC 0.741
- timestamp 그룹 AUROC 0.698, 무작위 대비 격차 0.043
- 미래 시간 AUROC 0.727, 무작위 대비 격차 0.014
- 미래 5구간 AUROC 범위 0.545~0.874

사전에 정한 0.05 격차 기준으로 그룹·시간 취약성 경고는 발동하지 않았다. 다만 여러 ROI 행이 동일 timestamp에 묶이는 비독립 구조는 외부 데이터에서도 확인됐다. 특정 미래 구간의 큰 하락은 결과를 본 뒤 발견한 탐색 결과이므로 확증 결과와 분리했다.

### 단계 4. 시간 강건성과 업무지표 개발 실험 — 완료

AUROC 대신 실제 운영 목표를 함께 평가했다.

- 목표: defect slip rate≤1%와 volume reduction≥40% 동시 달성
- timestamp-only AUROC 0.642
- 행 무작위 AUROC와 최악 미래 구간 AUROC의 차이 0.196
- 선형 모델 학습 구간: slip 0.99%, volume reduction 2.73%
- 미래 전체: slip 1.60%, volume reduction 2.66%
- 미래 5개 구간 모두 업무목표 미달

하지만 기준 모델이 학습 기간부터 volume 목표를 달성하지 못했다. 따라서 미래 실패를 시간 드리프트 때문이라고 해석하지 않고, 시간 평가 전에 학습 feasibility를 먼저 확인해야 한다는 절차적 결론만 채택했다.

### 단계 5. 고정 비선형 모델 feasibility gate — 완료

고정 HistGradientBoosting 모델을 50% 학습, 20% calibration, 30% 미래 평가로 실행했다.

- 학습 AUROC 0.997
- calibration AUROC 0.870, slip 0.62%, volume reduction 1.65%
- 미래 AUROC 0.878, slip 0.85%, volume reduction 3.16%
- calibration feasibility gate 미달

높은 AUROC와 낮은 slip을 얻었지만 수작업 물량을 40% 줄이지 못했다. 즉, 좋은 AUROC가 운영 가능성을 의미하지 않는다는 점을 다시 확인했다. 같은 데이터에서 모델을 계속 바꾸는 사후 선택은 중단했다.

### 단계 6. Siemens 논문 프로토콜 부분 재현 — 완료

Pfab & Rothering 논문에 공개된 40/10/10×5 분할과 5-fold 임계값 절차를 고정 Random Forest로 재구성해 10시드 실행했다.

| 구간 | 재현 slip | 논문 RFC2 slip | 재현 volume | 논문 RFC2 volume |
|---|---:|---:|---:|---:|
| 무작위 test | 1.16% | 1.0% | 71.58% | 89.7% |
| 미래 1 | 3.58% | 10.2% | 38.50% | 66.7% |
| 미래 2 | 1.94% | 14.6% | 38.33% | 52.4% |
| 미래 3 | 2.44% | 15.0% | 50.85% | 65.4% |
| 미래 4 | 7.21% | 10.9% | 54.08% | 76.0% |
| 미래 5 | 7.60% | 11.0% | 33.68% | 39.7% |

- 무작위 test gate 통과: 4/10시드
- 미래 업무목표 달성: 50개 시드-구간 중 0개
- 무작위 평가에서 미래 평가로 이동할 때 실패하는 방향은 재현
- 논문 RFC2와 절대 수치 차이가 커서 완전 재현이 아닌 부분 재현으로 판정

논문이 인용한 GitLab 코드는 현재 인증 없이는 접근할 수 없고 Bayesian optimization의 search space와 최종 hyperparameter도 공개 논문에 없다. 이 한계를 재현 실패와 구분해 기록했다.

## 4. 현재까지 얻은 핵심 결론

### 지금 증거로 말할 수 있는 것

1. 네 감사 지표는 대응하는 합성 데이터 병리에 일관되게 반응한다.
2. 합성 실험에서 감사 지표가 클수록 무작위 평가와 새 사건·새 시점 평가의 성능 격차가 커졌다.
3. 외부 Siemens 데이터에서도 행 수와 독립 사건 수가 다른 비독립 구조가 확인됐다.
4. AUROC만으로는 slip rate와 volume reduction의 동시 달성 여부를 알 수 없다.
5. 무작위 test의 양호한 결과가 미래 생산 구간의 업무 성능을 보장하지 않는 현상은 논문 프로토콜 부분 재현에서도 나타났다.

### 아직 말하면 안 되는 것

1. 네 지표가 모든 산업 검사 데이터에 일반화된다고 주장할 수 없다.
2. 현재 현장 데이터만으로 새로운 모델이 기존 검사 설비보다 실제 결함을 더 잘 찾는다고 주장할 수 없다.
3. Siemens 결과만으로 시간 드리프트와 성능 붕괴의 인과관계를 확증할 수 없다.
4. 공개되지 않은 원 코드와 hyperparameter 없이 논문 모델을 완전히 재현했다고 주장할 수 없다.
5. 실제 전문가 질의 실험 없이 암묵지 추출 효과를 주장할 수 없다.

## 5. 현재 논문으로 만들 수 있는 형태

### 가제

**Before Anomaly Detection: Auditing Label Provenance and Verdict Leakage in Industrial Inspection Data**

### 논문 중심 주장

산업 검사 AI의 실패는 모델 구조뿐 아니라 라벨 생성, 판정 렌더링, 독립 표본 단위, 시간 분할의 문제에서 시작된다. 따라서 모델링 전에 이 네 가지를 감사하고, AUROC와 함께 defect slip rate·volume reduction을 보고해야 한다.

### 예상 연구 질문

- RQ1. 전용 감사 지표가 라벨 순환성, 판정 오버레이, 날짜 교락, 사건 중복을 구분할 수 있는가?
- RQ2. 감사 지표가 무작위 평가와 새 사건·새 시점 평가의 성능 격차를 예측하는가?
- RQ3. 고정된 감사 프로토콜의 경고가 실제 외부 산업 데이터에서도 나타나는가?
- RQ4. 분류 성능지표와 실제 검사 업무목표 사이에는 어떤 차이가 있는가?

### 현재 가장 큰 빈칸

외부 데이터 검증이 Siemens 한 사례뿐이다. 합성 내부 타당도를 넘어 일반화 가능성을 주장하려면, Siemens 결과를 보고 고친 시간 지표와 업무지표를 독립적인 두 번째 외부 데이터에 적용해야 한다.

## 6. 다음 단계

### 단계 7. 두 번째 외부 데이터 검증

다음 실험 전에 아래 내용을 Git에 고정한다.

- 데이터셋 선정 기준과 제외 기준
- 독립 표본 단위 정의
- 네 감사 지표의 계산식과 임계값
- 시간 구간 최소 양성 사건 수
- slip rate≤1%, volume reduction≥40% 업무목표
- feasibility gate 통과 후에만 미래 시간 실패를 해석한다는 규칙
- 확증 분석과 사후 탐색의 분리 방식

Siemens에서 모델을 추가로 탐색하는 것은 우선순위가 아니다. 다음 핵심 증거는 독립적인 외부 데이터에서 같은 프로토콜이 어떤 판정을 내리는지 확인하는 것이다.

### 후속 암묵지 연구

데이터 감사로 해결되지 않는 항목만 전문가 질의 대상으로 만든다.

- 무엇이 정상이어야 하는가
- 어떤 예외가 의도된 것인가
- 실제 재작업 또는 폐기가 있었는가
- 신규 품종의 사양을 결정할 때 어떤 근거를 사용하는가

후속 연구에서는 질문 수, 응답시간, 반복 신뢰도, 질문 전후 설정 오류 또는 온보딩 시간 변화를 측정해야 한다.
